GitHub שומרת רישומים של כתובות IP של מבקרים לצורכי אבטחה, ועשויה לעבד את פרטי הבקשות לפי נוהלי האירוח והפרטיות שלה. זהו שירות נפרד מהאחסון הרפואי המקומי באפליקציה. המפתח לא הוסיף לדפים שירותי ניתוח שימוש, פרסום, סקריפטים למעקב, עוגיות, טפסים, חשבונות משתמשים או שירותי גופנים חיצוניים. התמונות והגופנים מוגשים עם האתר.

מעבר לקישור חיצוני או בחירה להשתמש בשירות דוא״ל, קבצים, יומן, שיתוף או רכישה מערבים את הספק המתאים ואת המדיניות שלו. Google מטפלת בהתכתבות ב־Gmail, GitHub מטפלת באירוח האתר ו־Apple מטפלת בשירותי הרכישה והמערכת שלה. תפקידים אלה אינם יוצרים ענן רפואי שמפעיל המפתח. האפליקציה אינה מעבירה את הרשומות הרפואיות המקומיות שלה באופן אוטומטי לאתר או לתיבת התמיכה.

שינויים במדיניות

המפעיל יעדכן את המדיניות כשפעולת האפליקציה או הדרישות החלות משתנות, ויציין את תאריך התחילה. הוספת שירות עתידי שמעביר מידע מרחוק תחייב החלטת מוצר נפרדת ועדכון המדיניות ובדיקת הצהרות הפרטיות ב־App Store.
